# 大作业功能对照清单

## 实体（数据模型）

| 要求 | 状态 | 表/API |
|------|------|--------|
| 歌曲 | ✅ | `songs` `/api/songs` |
| 视频 | ✅ | `videos` `/api/videos` |
| 艺术家 | ✅ | `artists` `/api/artists` |
| 用户 | ✅ | `users` `/api/auth` |
| 播放记录 | ✅ | `play_events`, `user_play_records`, `external_play_records` |
| 收藏夹 | ✅ | `favorites`, `video_favorites` |
| 歌单 | ✅ | `playlists`, `playlist_songs` |

## 基本操作

| 要求 | 状态 | API |
|------|------|-----|
| 上传/下架歌曲 | ✅ | `POST /api/songs/upload`, `POST /api/songs/<id>/offline` |
| 上传/下架视频 | ✅ | `POST /api/videos/upload`, `POST /api/videos/<id>/offline` |
| 用户注册 | ✅ | `POST /api/auth/register` |
| 播放/收藏 | ✅ | songs + videos 均有 play/favorite |
| 创建歌单 | ✅ | `POST /api/playlists` |
| 按播放量排行 | ✅ | `/api/rankings/all-time` |

## 高阶技术要点

| 要求 | 状态 | 实现位置 |
|------|------|----------|
| `DENSE_RANK()` 周/月榜 | ✅ | `v_hot_songs_weekly/monthly`, `v_hot_videos_weekly/monthly` |
| JSON 压缩播放时间序列 | ✅ | `user_play_records.play_timestamps_json`, `user_video_play_records` |
| 生成列 weight_score | ✅ | `duration_weight`, `base_score` + `v_songs_weighted` |
| 用户听歌偏好 | ✅ | `v_user_artist_preference`, `/api/preferences/me` |
